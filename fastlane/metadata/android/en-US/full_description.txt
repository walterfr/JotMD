JotMD is a native Markdown reader and editor for Android inspired by Typora, built 100% with Jetpack Compose and no WebView.

Block-based hybrid engine
- Only the focused block opens as plain text showing raw Markdown syntax; all other blocks stay rendered cleanly inline.
- The plain Markdown string remains the single source of truth, preserving original formatting byte for byte (including UTF-8 BOM).
- Live source mode with syntax highlighting and selective line-number gutter, plus Focus mode dimming inactive blocks.

Smart editing and extended Markdown
- Typora-style smart editing: automatic continuation of lists, numbered lists, tasks, and blockquotes on Enter, Tab/Shift+Tab indentation, empty-pair cleanup, cascade SmartBackspace, and coalesced undo/redo.
- Inline YAML front matter block at the top of notes.
- Aligned GFM tables (3x4 insert, add/remove/reorder rows and columns, alignment cycle), clickable task lists, fenced code blocks with syntax highlighting, and local image previews.
- GitHub Alerts ([!NOTE], [!TIP], [!IMPORTANT], [!WARNING], [!CAUTION]), ==highlight==, <u>underline</u>, LaTeX math ($...$ / $$...$$), [TOC] table of contents, clickable footnotes ([^id]), and reference links.

Workspace, search, and navigation
- Multi-tab editing with outline ("Indices") drawer, clickable [[wikilinks]] and #tags, and word count stats.
- Root folder note/folder CRUD via Storage Access Framework (SAF) without MANAGE_EXTERNAL_STORAGE.
- Folder-wide full-text search powered by SQLite FTS4 (accent-folding aware), in-note find/replace with regex (.*) and visual match highlights, and HTML-to-Markdown smart paste.

Themes, export, and privacy
- Five Typora presets (GitHub, Newsprint, Pixyll, Whitey, and dark Night).
- Export standalone HTML and native A4 PDF (with [TOC], alerts, tables, links, and footnotes) via the system picker.
- 100% offline, no ads, no tracking, MIT license.
